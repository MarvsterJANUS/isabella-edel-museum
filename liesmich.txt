START
  Datei „index.html“ im Hauptordner per Doppelklick im Browser öffnen.
  Es wird kein Server und keine Internetverbindung benötigt.

OPTIMIERT FÜR
  Aktuelle Version von Google Chrome bzw. Microsoft Edge (Chromium).
  Viewports: < 576 px, ≥ 576 px, ≥ 1400 px.
  Ansicht testen: Entwicklertools (F12) → Gerätesymbolleiste (Strg+Umschalt+M).

BEDIENUNG
  - Slider: wechselt automatisch alle 6 s; Pfeile, Punkte und Pause-Taste;
    auf Touchgeräten wischen. Jedes Bild verlinkt auf seine Unterseite.
  - Räume (≥ 576 px): Klick auf einen Raum im Gebäudeplan springt zur
    Beschreibung. Klick auf Museumscafé bzw. Eingang öffnet die Seite
    „Museumscafé“ bzw. „Tickets“. Smartphone (< 576 px): Sprung über die
    Legende unter dem Plan.
    Am Ende jeder Raumbeschreibung: „Zurück zum Gebäudeplan“ sowie
    Links zum vorherigen/nächsten Raum. Der angesprungene Raum wird markiert.
  - Bilder mit Lupe (Künstlerinnen, Räume): Klick öffnet die Großansicht;
    blättern mit Pfeilen bzw. Pfeiltasten, schließen mit ✕ oder Esc.
  - Tickets (Reservierung, Bezahlung bei Abholung an der Ticketkasse):
    1. Anzahl eingeben → Summe wird berechnet → „Auswahl bestätigen“
       (mindestens ein Ticket nötig) blendet die persönlichen Angaben ein.
    2. Pflichtfelder ausfüllen → „Bestellung abschließen und Tickets kaufen“.
    3. Die Bestätigungsseite zeigt das Ticket (Reservierungsbestätigung).
       „Ticket drucken“ druckt nur das Ticket (im Druckdialog auch
       „Als PDF speichern“), „Ticket als PDF herunterladen“ speichert es
       direkt als PDF-Datei (A4).
    Es werden keine Daten gesendet oder gespeichert (rein clientseitig,
    laut Aufgabe keine Formularfunktion/Bestätigungs-E-Mail gefordert).
  - Darstellung (im Menü, Desktop: runde Symbole neben „Tickets“):
    „Dunkler Modus“ schaltet zwischen hell und dunkel (Standard: Einstellung
    des Betriebssystems). „Barrierefreier Modus“: größere, serifenlose Schrift,
    höherer Kontrast, unterstrichene Links, keine Animationen/kein Autoplay.
    Die Wahl wird im Browser gespeichert (localStorage).
  - Ohne JavaScript bleibt alles nutzbar (Progressive Enhancement):
    Menü dauerhaft sichtbar, Slider als wischbare Bildleiste, Formular komplett.
