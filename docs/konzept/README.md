# Konzept (Teil a) – Entwürfe für Figma

Alle Dateien sind SVGs. In Figma einfach per Drag & Drop auf die Arbeitsfläche ziehen
(oder *Datei → Bild/Video platzieren*). Rechtecke, Texte und Pfade werden zu bearbeitbaren Ebenen.
Schriften: **Cormorant Garamond** und **Source Sans 3** (beide in Figma als Google Fonts verfügbar).

| Datei | Inhalt | Arbeitsplanung Teil a) |
|---|---|---|
| `sitemap.svg` | Seitenstruktur, Hauptnavigation, Slider-Links, Fußzeile | Nr. 2 |
| `wireframe-startseite-smartphone/-tablet/-desktop.svg` | Startseite in < 576 / ≥ 576 / ≥ 1400 px mit Anmerkungen | Nr. 3, 8 |
| `wireframe-raeume-smartphone/-tablet/-desktop.svg` | Räume mit viewportabhängigem Gebäudeplan, Legende, Raumbeschreibung | Nr. 3, 8 |
| `styleguide.svg` | Farben, Typografie, Raster/Breakpoints, Stilelemente | Nr. 4 |
| `piktogramme.svg` | Konstruktionsraster und Piktogramm-Familie (R1–R4, Service) | Nr. 6 |
| `gebaeudeplan.svg` | Isometrischer Plan: Variante Smartphone und klickbare Variante | Nr. 7 |
| `flowchart-raeume.svg` | Navigation Gebäudeplan → Raum → zurück (viewportabhängig) | Nr. 9 |
| `flowchart-progressive-enhancement.svg` | Mobile First und Progressive Enhancement in Stufen | Nr. 9 |
| `flowchart-tickets.svg` | Ablauf der Ticketreservierung | Nr. 9 |

Die orangefarbenen Nummern in den Wireframes verweisen auf die gelben Anmerkungen rechts daneben.
